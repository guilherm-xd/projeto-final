# DevJourney - Linha do Tempo da Evolução em Desenvolvimento Web

Uma página web em formato de **Timeline**, desenvolvida como Trabalho Final do primeiro semestre do curso de Desenvolvimento de Sistemas, utilizando exclusivamente **HTML e CSS**. O projeto apresenta de forma responsiva e animada os principais conteúdos estudados durante o semestre, além de uma seção pessoal sobre a evolução do desenvolvedor.

---

## Sobre o Projeto

Este projeto consiste em uma página fictícia da empresa **DevJourney**, especializada em registrar a trajetória de aprendizado de futuros desenvolvedores.

A proposta foi reunir, em uma única página, todo o conteúdo trabalhado ao longo do semestre, organizando os assuntos em uma linha do tempo horizontal e destacando o projeto atual em desenvolvimento.

O objetivo principal foi praticar HTML semântico, estilização avançada com CSS, animações com `@keyframes` e responsividade com Media Queries, sem o uso de JavaScript.

---

## Funcionalidades

- Header fixo (sticky) com navegação por âncoras
- Timeline horizontal com rolagem e snap entre os cards
- Linha de progresso animada acima da timeline
- Cards de projetos com destaque para o card em andamento (marcador "AGORA")
- Seção "Minha Evolução" com três painéis: quem eu era, quem eu sou agora e meu próximo objetivo
- Página separada de certificados (`certificados.html`)
- Animações de entrada em diversos elementos da página
- Layout totalmente responsivo (Desktop, Tablet e Mobile)

## Conceitos Aplicados

- HTML semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Variáveis CSS para definição da paleta de cores
- CSS Grid para a construção da timeline horizontal
- Flexbox para o header e a navegação
- `scroll-snap` para rolagem suave entre os cards
- `backdrop-filter` no header fixo
- Animações com `@keyframes`
- Media Queries em 1024px e 768px

---

## Animações Utilizadas

O projeto utiliza animações feitas com `@keyframes`, incluindo:

- **entrar-baixo** - elementos surgindo de baixo para cima ao carregar a página
- **entrar-lado** - título principal surgindo lateralmente
- **revelar-linha** - linha de progresso da timeline sendo revelada com `clip-path`
- **pulso** - efeito de pulsação contínua nos marcadores da timeline
